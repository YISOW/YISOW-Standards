## 读取与质量底线

全局入口保留持续适用的质量、权限与证据底线；下表决定本任务还需读取的原文。按需加载改变读取时机，不改变适用条款的效力。普通局部任务不重复读取全部原文；首次接入、重要恢复、范围明显变化或正式验收时扩大核查，既有项目明确要求完整读取时仍遵守。

先找项目已有的当前恢复入口、需求、有效决策、资产和验收条件。复用其命名与组织，不为了本库新建第二套 PROJECT_CONTEXT/状态/日志/批准台账。缺少当前事实时核实实际代码和产物；不能拿历史快照覆盖当前状态。

**外部协作与保留余量：** 当前只采用用户手动协作。用户需要时，Codex 筛选适合外部完成的任务，提供可复制提示词、最小材料和需要带回的差异/测试/风险；用户自行选择平台、模型和时间，带回结果后 Codex 复核验证及集成。不得自动操作外部客户端、调用外部智能体、传输资料、消费额度或建立定时任务。阻断即停，无新信息不循环重试。Codex 默认约20%开始收尾、约10%紧急保存，已有更严格停止线优先；保存已发提示词、待返还项、实际成果和继续入口，不虚构后台控制或额度能力。

## 本地与云端接入

### Windows 本地执行主机

安装源：[integration/AGENTS.global.md](integration/AGENTS.global.md)。这是模板，安装前将 `<YISOW_STANDARDS_ROOT>` 替换为执行主机实际可读的资料库绝对路径，再合并到该环境的全局 AGENTS.md；默认配置位置为用户目录下的 `.codex/AGENTS.md`，自定义配置位置按实际环境核实。尖括号占位符不会自动展开，不能原样作为可用配置。保留已有入口和项目决定，无需为已有项目新建 Skills。隔离环境不能读取本库时采用下述便携方式，不扩大实际权限。

全局 AGENTS.md 在新运行/新会话构建指令链；已启动的其他聊天不承诺立即重载，应在下一次新会话核对。AGENTS.override.md、自定义 CODEX_HOME、嵌套项目规则及读取大小限制可能影响实际行为。入口链接不会自动展开，须验证后续按路由读取。

### macOS 和其他本地执行主机

本机路径不会跨设备同步。把完整资料库复制或经授权检出到该执行主机，复用全局入口模板并填写该主机实际路径；合并已有全局入口而不覆盖。各主机单独校验、验证。当前没有 macOS 部署通过的证据。

### Codex Cloud、隔离工作树与项目便携副本

本地全局入口、个人 Skills、绝对路径不会自动成为云端文件。经授权在项目已有 `docs/standards/` 中提供固定版本副本（完整 standards/，含当前工作副本和索引引用的历史基线，另含本文索引、references/ 及相对目录结构），在项目原 AGENTS.md 中合并 [便携入口片段](integration/project-AGENTS.snippet.md)。版本/校验/授权来源集中在该索引，不增加锁文件或台账；本库是维护源，副本只随明确版本更新，不独立编辑原文。

也可在支持多仓库的云端环境中接入本库，但须实测检出路径和文件权限。远程仓库可读不等于已经接入云端。Windows/macOS/Android 是产品目标平台；Android 手机发起任务时取决于电脑或云端的实际执行位置；目标设备运行、签名、GUI 和真实效果仍须在相应环境验证。

外部智能体使用由用户手动交接的规范与项目材料。先提供本索引和当前规范，要求其说明实际读取的版本、相关章节、不可读项及任务边界，再按项目验收条件复核实际修改与证据。链接可访问或声称遵守不等于实际验收通过；外部工具不支持的能力须如实报告。本库公开不构成自动调用或传输任何项目资料的授权。
